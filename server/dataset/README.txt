Optional: put your Kaggle CSV files in this folder, then run `npm run train` (from /server).

Supported datasets
  - Disease Symptom Prediction (itachi9604):  dataset.csv  (+ symptom_Description.csv, symptom_precaution.csv)
  - Disease Prediction Using Machine Learning (kaushil268): Training.csv

The project already ships with data/model.json trained on the first dataset, so you do NOT need
to download anything just to run or deploy it. Retrain only if you want to use a different dataset.
